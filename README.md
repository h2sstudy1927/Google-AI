# H2S STUDY - Odisha State Competitive Exams Platform

Official open-source application for Odisha state government competitive examinations (OPSC, OSSC, OSSSC, OUSSSC, and Teaching Exams).

## 🚀 Live Demo
Once GitHub Pages is enabled, your live link will be:
`https://h2sstudy1927.github.io/Google-AI/`

## 🎯 Features
- **Strict Commission Marking**: +1.00 for Correct, -0.25 for Incorrect answers.
- **Colorful Exam Folders**: OPSC, OSSC, OSSSC, OUSSSC, and Teaching Exams.
- **Interactive Whiteboard & Live Classroom**: Low-data streaming (144p to 1080p).
- **AI Performance Mentor**: Pinpoints negative marking penalties on Odisha GK & Odia Grammar.
- **Role-Based Access Control**: Teacher authoring studio & candidate view with admin approval pipeline.
- **Persistent Offline & Cloud Storage**: Room database + Firebase Firestore sync.
